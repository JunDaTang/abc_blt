# ABC 作业成本法 — 物流成本分析系统

## 一句话说明

把一个快递公司每月花的钱，精确地算到每一个快递包裹上。

---

## 用例子理解 ABC

### 问题：100 万怎么分到 100 万个包裹上？

假设你开了一家快递公司，某个月：
- 总共花了 **100 万元**（人工、车辆折旧、油费、包装物料、管理费等）
- 一共送了 **100 万个包裹**

最简单的想法：每个包裹 1 元？但显然不公平——

- 同城件只用分拣+派送，成本应该低
- 跨省件还要长途运输，成本应该高
- 大客户一件 50kg，小客户一件 0.5kg，成本不可能一样

**ABC（作业成本法）的思路**：不是平均分，而是按"每个包裹实际消耗了什么"来分。

---

### 核心思想：追踪成本的流转路径

```
钱花在哪了？        → 谁用了这些钱？     → 干了什么活？      → 哪些包裹享受了？
（财务科目）          （功能中心）          （作业活动）          （运单/包裹）

  人工费 50万    →   分拣中心 20万    →   分拣作业 15万    →   包裹A分摊了 0.3元
  油费   30万    →   运输中心 30万    →   干线运输 25万    →   包裹A分摊了 1.2元
  折旧   20万    →   管理中心 10万    →   管理支持  8万    →   包裹A分摊了 0.1元
                                                           ──────────────────────
                                                           包裹A总成本 = 1.6元
```

### 四级分摊模型（代码的核心逻辑）

成本从财务科目流转到最终包裹，经过四步分摊：

#### 第 1 步：RR — 资源 → 资源（共享资源分给各部门）

> **场景**：公司有一栋办公楼，月租 10 万。运输部占 60% 面积，分拣部占 30%，管理部占 10%。

```
办公楼租金 10万
  ├── 运输部   6万  (60%)
  ├── 分拣部   3万  (30%)
  └── 管理部   1万  (10%)
```

代码对应：`7.2-RR分摊程序.prc`，规则配置在 `ABC_REL_RR_DIST`

#### 第 2 步：RA — 资源 → 作业（每个部门的资源分给各作业）

> **场景**：分拣部这个月总共花了 23 万（自己的 3 万 + RR 分来的），要分给各项作业：
> - 分拣作业消耗了 60% 的人工和场地 → 分 13.8 万
> - 打包作业消耗了 40% → 分 9.2 万

```
分拣部 23万
  ├── 分拣作业  13.8万  (60%)
  └── 打包作业   9.2万  (40%)
```

代码对应：`7.2-RA分摊程序.prc`，规则配置在 `ABC_REL_RA_DIST`

#### 第 3 步：AA — 作业 → 作业（辅助作业之间的分摊）

> **场景**：有些作业是辅助性的，比如"车辆调度"不直接处理包裹，但帮了"干线运输"的忙。要把调度的成本分给运输。

```
车辆调度作业 5万
  └── 干线运输作业  5万  (100%，因为调度只服务运输)
```

代码对应：`8.2-AA分摊程序.prc`，规则配置在 `ABC_REL_AA_DIST`

#### 第 4 步：AO — 作业 → 运单（最终分到每个包裹）

> **场景**：分拣作业这个月总成本 13.8 万，处理了 10 万个包裹。
> 但包裹 A 是同城件（只分拣 1 次），包裹 B 是跨省件（中转分拣 3 次）。
> 按"分拣次数"作为动因分配：
> - 包裹 A：1 次 × 单价 → 分摊 1 元
> - 包裹 B：3 次 × 单价 → 分摊 3 元

```
分拣作业 13.8万 ÷ 总动因量(分拣次数) = 单价
  ├── 包裹A  1次 → 分摊 1元
  ├── 包裹B  3次 → 分摊 3元
  └── ...百万个包裹各自分摊
```

代码对应：`8.2-AO分摊程序.prc`，规则配置在 `ABC_REL_AO_DIST`

---

### 最终产出：每个包裹的成本明细

四步分摊完成后，每个包裹都有了成本明细，可以回答这些业务问题：

| 分析维度 | 问题示例 |
|---------|---------|
| **区部利润** | 北京区部这个月赚了多少？（收入 - 成本） |
| **流向利润** | 北京→上海这条线路赚钱吗？北京→广州呢？ |
| **客户利润** | 大客户 A 到底给公司贡献了多少利润？ |
| **产品利润** | 次日达和标准件，哪个更赚钱？ |
| **成本结构** | 我们的成本主要花在运输还是人工？ |

这些分析都在 `ABC_BSL_COST_BASE`（成本分析基表）上完成，对应 `9.1-分析脚本.sql` 和 `10.3-分析脚本.sql`。

---

## 代码执行顺序

先建表，再灌基础数据，再按顺序跑四级分摊，最后汇总分析：

```
3.x 建资源维度表       →  4.x 导入运单/机构/财务数据
        ↓
5.x 配置分摊规则       →  6.x 计算动因量
        ↓
7.x RR分摊  →  RA分摊  →  8.x AA分摊  →  AO分摊
                                            ↓
                                   10.x 汇总到成本基表
                                            ↓
                                      9.x 利润分析
```
